Cloud Computing Course Project

AI-Powered Personal Diet Planner with Cloud Storage

A full-stack demo that showcases cloud computing concepts end to end: authentication, a cloud database, cloud object storage, a REST API, and an AI-assisted recommendation engine with automatic fallback. Built with synthetic demo data for educational purposes.

Get Started I already have an account

☁️ Cloud Storage & Database

Your profile and plans live in a cloud database; uploaded files live in cloud object storage — kept separate, just like in production systems.

🤖 AI Diet Engine

A rule-based recommendation engine generates breakfast, lunch, snack, and dinner suggestions, with an optional AI-API mode and automatic fallback.

🔐 Secure by Design

Passwords are hashed, sessions use JWTs, and every user's data is isolated from every other user's.

📊 Personal Dashboard

Track your goal, diet preference, latest plan, history, and uploaded files in one place.

Disclaimer: This project uses synthetic/demo data only. Generated diet plans are educational/general wellness examples and are not medical or clinical nutrition advice.
